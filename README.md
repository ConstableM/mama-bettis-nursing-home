# Mama Betti's Nursing Home

A responsive static website for GitHub Pages. No build tools required.

## Publish on GitHub Pages
1. Create a new public GitHub repository (e.g. `mama-bettis-nursing-home`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages** and select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. Your site will appear at `https://YOUR-USERNAME.github.io/mama-bettis-nursing-home/` after deployment.

## Customize before publishing
- Replace `hello@example.com` in `index.html` with a real email address.
- Add the home's real phone, address, hours, and verified services if desired.
- Replace the two demo Unsplash image URLs with photos you have permission to publish (prefer local image files in an `images/` folder).
- Review all copy for accuracy, especially any care-related claims.

No resident photos or personal details should be posted without appropriate permission.
